# `HTMLTemplates.swift` is hand-maintained; never reformat it

`Sources/XCTestHTMLReportCore/Classes/HTMLTemplates.swift` is the source of
truth for the report's markup, styles and scripts. Edit its strings directly.
It once carried a "DO NOT EDIT! This file is autogenerated" header, but its
generator, `createTemplates.sh`, was deleted in #295, and #452 (for #434)
replaced the header and deleted the stale `HTML/` copy. Notes calling it
generated are wrong.

It is almost entirely multiline string literals whose contents are the
emitted HTML. In Swift, the indentation of a literal's closing `"""` decides
how much leading whitespace is stripped from every line, so a formatter that
moves those delimiters **changes the bytes of every generated report**.

That is why it is excluded in `.swiftformat` and `.swiftlint.yml`, and why the
`swiftlint` step in `hk.pkl` skips it (a commit touching only this file would
otherwise fail with "No lintable files found"). Keep those three in step.

A template change shows up in `TemplateSnapshotTests`; refresh the goldens as
`CONTRIBUTING.md` describes and read the diff.
